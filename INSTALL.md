# 安装与开始使用 / Install and start

## 中文

```text
ASPECT Chat 安装与使用

1. 安装并启动 Docker Desktop（Linux 也可用 Docker Engine）：
https://docs.docker.com/get-started/get-docker/

2. 下载启动包并解压：
https://github.com/shaohuiliu-github/aspect-chat/releases/download/v1.1.0/ASPECT-Chat-1.1.0-online.zip

3. 启动：
Mac：右键 Start.command → 打开。
Windows：Docker 使用 Linux 容器模式，双击 Start.bat。
Linux：在解压目录运行 bash start.sh。
首次启动会自动下载环境，等待浏览器打开即可。

4. 在“设置”里选择服务商并填写 API 密钥，在对话顶部选择模型，即可开始使用。

以后直接打开 Start；停止应用用 Stop。
```

## English

```text
ASPECT Chat — Install and start

1. Install and start Docker Desktop (Docker Engine also works on Linux):
https://docs.docker.com/get-started/get-docker/

2. Download and extract the launcher:
https://github.com/shaohuiliu-github/aspect-chat/releases/download/v1.1.0/ASPECT-Chat-1.1.0-online.zip

3. Start:
Mac: right-click Start.command → Open.
Windows: use Linux containers in Docker, then double-click Start.bat.
Linux: run bash start.sh in the extracted folder.
On first launch, wait for the environment to download and the browser to open.

4. In Settings, select your provider and enter your API key. Choose a model at the top of the chat, then start using the app.

Next time, open Start again. Use Stop to stop the app.
```
