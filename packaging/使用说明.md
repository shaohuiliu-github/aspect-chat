# chatGFD：四步开始使用

1. 安装并打开 [Docker Desktop](https://www.docker.com/products/docker-desktop/)，等待启动完成。
2. Mac 按 **⌘ + 空格**，搜索「终端」并打开。输入 `bash `（后面有一个空格），把本文件夹的 **start.sh** 拖进终端，按回车。Windows 双击 **Start.bat**；Linux 在本文件夹运行 `bash start.sh`。
3. 第一次会自动下载环境，等待终端显示网址，然后用浏览器打开那个网址。
4. 点击左下角 **Settings（设置）**，填写 API 密钥并保存。在对话框输入你想建立的模型，发送即可。

**下次使用：** 打开 Docker Desktop，再重复第 2 步。无需重新下载启动包。

**结果在哪：** 本文件夹的 `workspace/runs`。上传论文、图片或参数文件请用对话框中的上传按钮。

**如何停止：** Mac 在终端输入 `bash `，拖入同一个 `start.sh`，再输入 ` stop`，按回车。Windows 双击 `Stop.bat`。关闭终端不会停止运行。
