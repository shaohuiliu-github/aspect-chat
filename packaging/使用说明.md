# chatGFD 2.0.3

先安装并启动 Docker。Mac 打开 Start.command，Windows 打开 Start.bat（使用 Linux 容器），Linux 运行 bash start.sh。打开显示的本地网址，在设置里填写 API 密钥；左上角选择 ASPECT 或 i2vis，对话框下方选择大模型。

Mac 首次打开若出现“Apple 无法验证 Start.command”，先尝试打开一次，再到「系统设置 → 隐私与安全性」点「仍要打开」并确认。只对从 chatGFD 官方仓库下载且你信任的文件这样操作；也可以在此文件夹的终端运行 `bash start.sh`。说明：https://support.apple.com/en-ie/102445

论文、图片和参数文件都在对话框上传。参数文件可以手动编辑、检查、运行，无需额外调用大模型。运行状态和错误直接显示在对话中，每个任务下方可展开日志。结果保存在 workspace/runs；停止时打开对应的 Stop 文件。

初始图由独立代码读取参数绘制，不启动模拟；不支持的输入会说明原因。参考黏度不等于非线性求解后的有效黏度。论文复现先核对物理参数、页码、单位、换算与假设，再核对数值收敛。已安装 i2vis 的来源、便携求解后端及测试范围见许可说明和验证报告。
