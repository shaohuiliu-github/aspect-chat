# chatGFD 2.0.5

先安装并启动 Docker。Mac 打开「终端」，输入 `bash `（保留后面的空格），将本文件夹的 `start.sh` 拖入终端，按回车。Windows 双击 `Start.bat`（使用 Linux 容器）；Linux 在此目录运行 `bash start.sh`。打开显示的本地网址，在设置里填写 API 密钥；左上角选择 ASPECT 或 I2VIS，对话框下方选择大模型。

Mac 启动包不再包含未经 Apple 签名的 `.command` 快捷方式。首次运行会自动下载容器镜像，请等终端显示本地网址；以后仍用同一步骤启动。需要停止时，在终端输入 `bash `，拖入同一个 `start.sh`，再输入 ` stop` 并回车。终端关闭后容器继续运行；模型和结果保存在 `workspace`。

论文、图片和参数文件都在对话框上传。参数文件可以手动编辑、检查、运行，无需额外调用大模型。运行状态和错误直接显示在对话中，每个任务下方可展开日志。结果保存在 `workspace/runs`；Mac/Linux 用 `bash start.sh stop` 停止，Windows 双击 `Stop.bat`。

初始图由独立代码读取参数绘制，不启动模拟；不支持的输入会说明原因。参考黏度不等于非线性求解后的有效黏度。论文复现先核对物理参数、页码、单位、换算与假设，再核对数值收敛。已安装 i2vis 的来源、便携求解后端及测试范围见许可说明和验证报告。
