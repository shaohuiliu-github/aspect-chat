# ASPECT Chat 1.1.1

本包包含 ASPECT 3.1.0、MPI、Python、对话界面、官方源码与算例、官方手册和运行时参数知识库。无需安装 ASPECT、Python或单独配置知识库。对话调用你自己选择的 API，计算在本机进行，输出为正常 ASPECT 文件。

## 发给别人后怎么用

1. `online` 联网启动包很小，首次从公共容器仓库下载环境；仓库正式发布并通过匿名下载验证后即可使用。`universal` 通用离线包包含两种运行镜像，启动时自动选择。若需要更小的单架构包：Apple 芯片 Mac 用 arm64；Intel Mac、常见 Windows 和 Linux 电脑用 amd64。
2. 先安装并启动 [Docker Desktop](https://docs.docker.com/get-started/get-docker/)；Linux 可以使用 Docker Engine。Windows 请启用 Linux containers，按 Docker 提示启用 WSL 2。Mac 如果已经使用 Colima，也可以直接使用它。
3. 将整个压缩包解压到本地磁盘，路径可以包含空格或中文。不要直接在压缩包内部运行。
4. Mac 双击 `Start.command`；Windows 双击 `Start.bat`；Linux 在此目录运行 `bash start.sh`。首次需要下载或导入镜像，等待浏览器自动打开。
5. 在“设置 → 连接”选择服务商、输入自己的 API 密钥。对话顶部选择模型。中文与英文可在左下角切换。
6. 在“设置 → 计算”设置单任务核数、最多同时使用的核数、时间上限；Docker 分配的 CPU 和内存也应足够。大型三维模型需要根据实际规模增加 Docker 内存。

Apple 芯片 Mac 的当前制作环境已经安装 Colima 和 Docker CLI，因此这里不需要你手动安装 Docker Desktop。

## 模型与结果在哪里

解压目录下的 `workspace` 是持久工作目录，不在容器的临时磁盘内：

- `cases/<模型编号>/draft.prm`：当前参数文件；`versions/`：此前版本；`assets/`：WB、ASCII 等输入文件。
- `runs/<任务编号>/input.prm`：本次运行参数快照；`output/`：ASPECT 结果；`run.log` 和 `validate.log`：日志。
- `batches/`：参数扫描汇总。
- API 密钥和聊天记录也只保存在自己的 `workspace`，不要把使用后的工作目录直接转发给别人。

用 ParaView 等软件直接打开 `workspace/runs/.../output`。界面显示的是电脑上的路径。启动窗口保持打开时，“打开文件夹”按钮可启动 Finder / Explorer。关闭启动窗口后计算继续，重新打开 Start 即可恢复文件夹按钮。

## 上传论文、图片和已有模型

PDF、图片、PRM 可直接上传到对话。带相对路径输入文件的模型建议把 PRM 和 WB / ASCII 数据放进一个文件夹后压缩为 ZIP 上传；优先将入口命名为 `model.prm` 或 `input.prm`。多个入口时，可在模型文件面板底部使用本地导入路径。

也可以将完整模型文件夹复制到 `workspace/inputs/`，从模型文件面板底部的本地路径导入入口 PRM。此时输入该文件在自己电脑上的完整路径。容器只能访问本包的工作目录，不能直接读取任意电脑文件夹。

初始密度、温度、黏度预览沿用现有方式自动生成。图片转密度模型仍须提供色标、坐标和物理转换关系；论文未给出的参数由对话说明假设。描述预期效果会生成可运行的候选模型，并不等同于已实现自动反演优化。

## 停止、继续和搬迁

- 关闭浏览器不会停止任务。
- 运行 `Stop.command` / `Stop.bat` / `bash start.sh stop` 会停止容器和正在运行的任务，保留所有文件。运行中的任务记为中断；下次启动不会冒充已经成功或自动恢复到检查点。需要续算时在对话中配置 ASPECT 的 resume 设置。
- 再次打开 Start 会启动同一工作目录。先 Stop，再搬迁整个文件夹；容器内的固定 `/workspace` 路径不随电脑改变。
- 更新软件时先 Stop，保留并复制自己的 `workspace` 到新版目录；不要用空白目录覆盖它。
- 要发给别人，使用原始发布压缩包，不要把自己的 `workspace`、API 密钥、模型和聊天历史打包进去。

## 知识库与源码

内置只读知识库以 ASPECT 3.1.0 为运行版本，包含官方完整源码、全部 1,796 个 PRM 文件、293 页手册、1,159 页官方 API、1,696 个独立运行时参数条目、辅助脚本与笔记本、算例输入依赖目录，以及 World Builder 1.1.1 的实际参数 schema。每条资料保留来源和版本。默认搜索只使用与运行环境对应的资料；当前开发版源码及 Wiki 导航必须显式选择，并标为参考资料，不能直接当作可运行算例加载。模型检索会优先完整算例，手册片段不会误当成独立模型。仍须以实际 `--validate` 和运行日志确认兼容性；需要额外插件的算例未必可直接运行。

本镜像启用了 World Builder，未启用 FastScape。自定义编译插件需要与镜像的 Linux、ASPECT 和 deal.II 版本匹配；Mac 的 `.dylib` 或 Windows 的 `.dll` 不能直接用于这个 Linux 求解器。

离线包和源码包中的 `source/` 包含应用代码、Dockerfile、依赖清单与知识库。联网包的对应源代码、知识库和许可在镜像内 `/opt/aspect-chat/`；可运行 `docker cp <容器名>:/opt/aspect-chat ./source` 导出。官方 ASPECT 源码及许可在 `knowledge/sources/aspect-3.1.0/`。`knowledge/manifest.json` 记录来源和版本；`验证报告.json` 记录实际验证范围。

离线指 ASPECT、应用和知识库已打包；使用云端模型对话仍需要互联网和自己的 API 额度。本包没有预装大语言模型权重。

## 如果启动失败

查看 `workspace/container-start.log` 和终端提示。最常见原因是 Docker 未启动、Windows 未启用 Linux containers、镜像架构不符、磁盘或 Docker 内存不足。默认端口 8517 被占用时启动器会选择后续空闲端口。只监听 `127.0.0.1`，不开放到局域网。

首次运行 Mac 的下载压缩包可能被系统提示为来自互联网；在确认来源后使用 Finder 右键“打开”。Linux 若当前用户没有 Docker 权限，请按 Docker 官方说明配置；不要把本应用作为 root 运行。
